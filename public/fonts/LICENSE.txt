WordWarp bundled fonts — third-party licenses and attribution
============================================================

These font files are third-party works, excluded from WordWarp's Unlicense.
Eleven families use the SIL Open Font License 1.1; Luckiest Guy and Slackey
use the Apache License 2.0. Their original licenses and notices remain in effect.

Complete, unmodified per-font license texts are in the licenses/ directory
beside this index. Keep that directory with redistributed fonts and app builds.
The OFL requires its fonts to remain under the OFL; it does not apply its
license to artwork created using the fonts. Apache-2.0 requires preservation
of the applicable license and notices. Read each complete license for its terms.

The fonts are prebuilt Latin WOFF2 subsets; Baloo 2 is a variable font. All
thirteen bundled files match the version-pinned Fontsource 5.3.0 files recorded
in SOURCES.json, byte for byte. WordWarp has not modified or regenerated them.
The original import did not record download URLs; the matching distributions
were verified on 2026-09-29. The binary and license SHA-256 hashes, exact URLs,
font versions and binary copyright strings are recorded in SOURCES.json.

Reserved Font Names are preserved in the original license files. Keep the
original names for these unchanged distributor files. Before making a modified
font, review the relevant OFL naming condition; a reserved name needs the
copyright holder's permission or a compliant new name.

The copyright lines below reproduce the bundled font name tables (line breaks
normalized for display). The complete per-font license files additionally
preserve the distributor's notice, including any differences from the binaries.
